# Music Producer/DJ Sunny — Artist Website

A minimal, cinematic electronic-music artist website designed for static hosting.

## Edit first

Open `index.html` and replace:
- Instagram URL
- YouTube URL
- Spotify URL
- SoundCloud URL
- TikTok URL
- Booking email
- Release links
- Release description
- Video links/titles

## Assets

Put your real artist photo, release artwork and video thumbnails in `assets/` when ready.

## Deploy

This is a plain static website, so it needs no server or database.

Cloudflare Pages:
- Build command: `exit 0`
- Build output directory: `/` (project root)
- Production branch: `main`

Or deploy to any static host.
